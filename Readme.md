### HealthVerse AI — Intelligent Medical Report Analysis
> RAG + CNN fusion for medical report understanding. 93.6% diagnostic accuracy. 60% faster retrieval.

The latency problem took longer to solve than training the model. BGE Embeddings chosen over OpenAI Ada for domain-specific biomedical text; ChromaDB over FAISS for persistent, filterable, metadata-rich storage.

| | |
|---|---|
| **Scale** | 5,000+ medical image records processed and indexed |
| **Accuracy** | 93.6% diagnostic classification on held-out test set |
| **Retrieval** | 60% latency reduction via optimized ChromaDB + BGE vector search |
| **Stack** | PyTorch · FastAPI · ChromaDB · BGE Embeddings · Streamlit · Docker |

→ [github.com/Ganeshpawar74/HealthVerse-AI](https://github.com/Ganeshpawar74/Intelligent-Medical-Report-Analysis-System-with-AI-Diagnosis-RAG-Based-Insights-)
